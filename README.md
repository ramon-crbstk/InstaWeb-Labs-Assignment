What I Built
This project is a drag-and-drop website builder developed using HTML, CSS, and vanilla JavaScript. It does not use any external libraries or frameworks and offers users an interactive way to design simple web layouts.

Key Features:
Sidebar with draggable elements: Text, Image, and Button

Canvas area for placing elements through drag-and-drop

Property editor form to update:

Text content or image URL

Font size

Font color

Mobile-responsive user interface

Minimal, clean, and intuitive design

How It Works
The user drags an element from the sidebar and drops it on the canvas.

The dropped element appears at the dropped position and becomes movable.

Clicking on the element loads its current properties into the form.

The user can update the content, font size, or color and click "Apply" to see the changes instantly.

The project demonstrates DOM manipulation, event handling, and dynamic styling using JavaScript.
